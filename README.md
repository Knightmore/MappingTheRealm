# MappingTheRealm

 ![MappingTheRealm](/images/icon.png)

Repo: https://puni.sh/api/repository/knightmore

MappingTheRealm is a standalone Dalamud plugin for smart travel in Final Fantasy XIV. 
It uses vnavmesh for local movement and plans routes across zones using aetherytes, aethernet, chocobo porters, and other in-game transport. 
Travel to map flags, housing plots, vendors, or saved addresses from the UI or with /mtr. 
Preview each route, track progress, and cancel from the floating status display. Other plugins can request travel and check reachability through IPC.
